## Возможности

- Праздничный стартовый экран с визуальным эскизом зимнего сада.
- Настоящая трёхмерная ёлка из отдельных иголок, тёплые гирлянды, отражающие украшения, мягкие тени и свечение.
- Ночной панорамный зимний лес, снег, фонари и подарки.
- Обзор вокруг ёлки и прогулка от первого лица внутри круглого сада.
- Три световых настроения, световой всплеск при загадывании желания.
- Подарки в 3D можно нажать: они открывают поздравление жюри.
- Музыка с колокольчиками длится 96 секунд и запускается после входа. Её можно выключить и запустить повторно.
- Небольшая подпись автора, поздравление и описание проекта на русском и белорусском языках.
- Адаптация для телефона и компьютера; поддержка уменьшенного движения.

Начальный экран использует созданный визуальный эскиз. После входа открывается сцена WebGL с объёмной геометрией, доступная для свободного осмотра.

## Локальный запуск

Сборка и установка пакетов не нужны. Все ресурсы включены в репозиторий.

Из корневой папки проекта запустите:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Требуется современный браузер с WebGL. Для JavaScript-модулей нужен HTTP-сервер, двойной щелчок по index.html не подходит.

Для размещения на статическом хостинге загрузите файлы проекта с сохранением структуры.

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Сайт работает из подпапки репозитория; сборка не нужна.

## Управление

- «Войти в зимний сад» — открыть 3D и включить музыку.
- «Обзор»: перетаскивание мышью или пальцем — вращение; колесо или жест двумя пальцами — приближение.
- «Прогулка»: WASD или стрелки — движение; перетаскивание — осмотр. На сенсорном устройстве появляются кнопки движения.
- Постамент и внешний периметр ограничивают прогулку.
- Кнопка «Начало» возвращает стартовый экран; круговая стрелка возвращает общий вид ёлки.
- RU / BE переключают язык, выбор сохраняется в браузере.
- «Подарок жюри» или нажатие на подарок под ёлкой открывают поздравление. Escape или крестик закрывают его.
- Кнопка звука включает/выключает музыку, снежинка включает/выключает снег.

## Файлы и лицензии

- `index.html` — структура; `style.css` и `interface.css` — оформление и адаптивный интерфейс.
- `app.js` — тексты RU/BE, интерфейс, музыка.
- `winter-scene.js` — геометрия, материалы, освещение, прогулка и взаимодействие.
- `assets` — локальные модули Three.js 0.170.0 (MIT), шрифты, изображения и лицензии.
- Manrope и Cormorant Garamond распространяются по OFL; лицензии включены в `assets`.
- `winter-reference.webp`, `winter-panorama.webp` — изображения, созданные встроенным ImageGen для этого проекта.

## Оптимизация для телефона

- Неподвижные детали объединены в общие буферы геометрии; кликабельность подарков сохранена.
- Тени рассчитываются один раз. Свечение огней выполнено без многошаговой обработки всего экрана.
- Хвоя и количество частиц адаптированы для телефона; снег анимируется на видеокарте.
- Камера обновляется на каждом кадре дисплея, движение и поворот сглажены. Разрешение 3D автоматически снижается при устойчивой нагрузке.
- На начальном экране, при чтении открытки и в скрытой вкладке 3D-отрисовка останавливается.
- На компьютере управление находится на отдельной панели; на телефоне — в компактной верхней строке и нижней панели. Учтены горизонтальный режим, вырезы экрана и нижняя безопасная зона.
- Сохранены прогулка, музыкальный фон, три настроения, поздравление RU/BE и подпись с Мухавцом.
